Why this page exists

The capstone requires the widget to render and submit from an origin it does not control. This page is served from http://localhost:5500 while the API runs on http://localhost:3000. Different port, different origin: the browser enforces CORS, sends a preflight OPTIONS request, and blocks the submission unless the API answers correctly.
